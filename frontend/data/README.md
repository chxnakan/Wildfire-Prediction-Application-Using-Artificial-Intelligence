# Thailand provincial boundaries

`thailand-provinces.geojson` is derived from **geoBoundaries gbOpen / OpenStreetMap / Wambacher**, Thailand ADM1, boundary ID `THA-ADM1-36821470`, represented year **2017**, 77 units, revision `9469f09`.

- [Source metadata](https://www.geoboundaries.org/api/current/gbOpen/THA/ADM1/)
- [Pinned simplified GeoJSON](https://github.com/wmgeolab/geoBoundaries/raw/9469f09/releaseData/gbOpen/THA/ADM1/geoBoundaries-THA-ADM1_simplified.geojson)
- [Open Data Commons Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/)
- [OpenStreetMap attribution and copyright](https://www.openstreetmap.org/copyright)

The derived boundary database remains available under ODbL 1.0. Changes: coordinates rounded to six decimal places, concise ISO province codes, English and Thai display names, and provenance metadata. Geometry is otherwise the supplied simplified geometry. The complete derived database is included here and served at `/dashboard/data/thailand-provinces.geojson`. It was copied unchanged from the companion FireWatch project.

These boundaries support approximate map filtering, not authoritative legal boundary decisions. Near-border and small-island locations can differ from finer or newer boundary datasets. The interface states this limitation. Province lookup runs in the browser; no location data are sent to a remote geocoding service.
