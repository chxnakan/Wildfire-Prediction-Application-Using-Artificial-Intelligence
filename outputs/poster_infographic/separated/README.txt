Separated Model Performance & Validation panels

Each component is exported as a 300-DPI PNG and an editable vector SVG.
01: Overall performance
02: Confusion matrix
03: ROC curve
04: Precision-recall curve
05: All three key-result cards
06: Evaluation information
07-09: Individual ROC-AUC, recall, and precision cards

These exports preserve the original style and real 72-hour test results.
Use the evaluation-information strip beside charts when assembling the poster.
Satellite hotspots are not confirmed wildfire incidents.

Reproduce: install requirements.txt, then run python create_infographic.py
The script produces the full infographic and the separated/ exports.
